# Paranoid Highlighter

клиентский мод под fabric 1.21.11. подсвечивает предметы, которые ты сам добавил в список: на земле, в рамках, на стойках, на витринах, на мобах и других игроках, в вагонетках с сундуком и в лодках. сундуки, бочки и шалкеры, которые уже прогружены, обводятся цветной рамкой.

на сервер ничего не уходит. список лежит в `config/paranoidhighlighter.json`.

`Y` включает и выключает подсветку, `N` добавляет предмет из руки. клавиши можно переназначить. меню мода открывается через Mod Menu. у каждой записи есть цвет и режим `Точно` / `Тип`: точно сравнивает компоненты, тип смотрит только на предмет.

нужна java 21.

```
./gradlew build
```

jar появится в `build/libs/paranoidhighlighter-1.1.0.jar`, кидаешь в `mods` рядом с fabric api.
